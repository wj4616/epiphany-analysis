## Tesla measurement plan

Success is observable when the commission brief document is produced and an AI agent, given only the brief as input, performs each of the following actions and produces the specified measurable outcomes:

1. **Phase-gate test:** The agent reads the brief and correctly identifies the Tier 1 KB completion gate — it does NOT invoke brainstorming or writing-plans skills until all Tier 1 items are confirmed present. *Measurable: agent halts or prompts for Tier 1 completion before proceeding.*

2. **Bridge completeness test:** The agent traces a creative intent phrase (e.g., "warm ambient pad") through the forward bridge chain and produces a complete set of DSP parameters. *Measurable: output contains all six bridge components, and the phrase appears verbatim as a cache key.*

3. **Quality priority test:** The agent, when facing a trade-off between DSP audio quality and UI polish, selects DSP audio quality without prompting. *Measurable: agent choice aligns with priority ordering (#1 > #5).*

4. **Scope exclusion test:** The agent, when asked about reverb, EQ, or compression plugin development, refuses or redirects based on the scope exclusion constraint. *Measurable: agent does not produce specifications for excluded segments.*

5. **Milestone distinction test:** The agent produces intermediate phase outputs that meet "technically functional" (VST3 loads in DAW) criteria, and reserves "commercially viable" criteria for the final release. *Measurable: intermediate outputs lack licensing/anti-piracy requirements; final output includes them.*

6. **Dual-reader test:** A C++ beginner reads the developer-rationale sections and can describe what the system does without reading the AI-executable specification. *Measurable: non-C++ reader achieves correct understanding of purpose and constraints from rationale sections alone.*

7. **Verification completeness test:** All 23 verification checklist items are addressed in the brief. *Measurable: count of addressed items = 23.*
