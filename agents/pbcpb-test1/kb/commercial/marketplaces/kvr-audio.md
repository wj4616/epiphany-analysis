## Summary

KVR Audio is both a product database and marketplace. With 37,000+ products from 3,700+ developers, it's a primary destination for plugin discovery.

## Business Model

| Aspect | Details |
|--------|---------|
| Database | Free listing for any audio software |
| Marketplace | Dealer margin covers all fees |
| Revenue Model | No additional fees for direct sellers |

## Listing Process

### Step 1: Database Entry (Free)

1. Create account at kvraudio.com
2. Submit product via "Submissions" page
3. Provide: name, description, format, OS, price
4. Wait for approval (typically 1-3 days)

### Step 2: Marketplace Setup

1. Create Manufacturer account
2. Set up Developer Dashboard
3. Configure pricing and promotions
4. Choose inventory method:
   - **Direct Sales**: Upload license codes to License Silo
   - **Distribution**: Connect via Xchange/Plugivery/Ilio

## Listing Requirements

- Product must be in database first
- Manufacturer account required
- Valid download/demo link
- Accurate format/OS info
- Pricing in USD

## Best Practices

1. **Complete profile** - Fill all fields, add screenshots
2. **Active forum presence** - Engage with community
3. **Regular updates** - Respond to comments, update changelog
4. **Demo version** - Essential for evaluation
5. **Good screenshots** - Show interface clearly
